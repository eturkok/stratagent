# StratAgent 0.10.0 — Developer Preview

Install once, ground recommendations in selected project evidence, and maintain
the reviewed workspace as the project evolves. Work through your existing coding
host and model; no additional model API key is required.

## Changes since 0.9.0

- Isolated source installer and runtime-bound project connection, without shell
  activation or global host-setting changes.
- Explicit selected project documents as current local evidence, with bounded
  reads, sensitive-text withholding and stale-context invalidation.
- Request coverage and selected-resource reasons, actual source quotes,
  alternatives and visible gaps. Exact duplicate bundles are refused.
- `maintain`: one local change summary and explicitly reviewed hash-only
  observation checkpoints, preserving drift/recovery and scan opt-out.
- `handoff --host`: a local scope/installed-decision/provenance summary without
  transferring conversations, approvals, native runtime guarantees or activation.
- A reproducible paired task-acceptance benchmark. The first maintainer-run
  comparison is documented separately; it does not establish general superiority.
- Publication identity updated for the repository's move to `eturkok/stratagent`,
  while earlier release-manifest URLs remain verifiable.

## Install and use

Python 3.11+ is required. From this reviewed source checkout:

```sh
python3 scripts/install.py --workspace /absolute/path/to/project --host codex
```

Use `python` on Windows. The installer prints the exact launcher and a short
instruction for your coding agent. Read the [setup guide](../quickstart-development.md)
for offline wheels, upgrades, host selection and the natural-language workflow.
See [maintenance and handoff](../maintenance-handoff.md) for repeated use.

Attested native bundles, the universal application wheel and source archive are
published by the [preview workflow](../publishing.md) only after all six exact-main
CI jobs pass. Workflow presence or a local build is not proof of publication.
PyPI publisher/account setup is separate; no PyPI listing is assumed.

## Boundaries

This remains a developer preview. Local metadata and model judgments are evidence
for review, not proof of semantic coverage, source safety, host loading or user
preference. No arbitrary resource code, MCP server or agent is automatically run.
Previously waived multi-host/human/independent-install trials remain unevaluated.
See [readiness](../release-readiness.md), [support](../../SUPPORT.md) and
[security](../../SECURITY.md).
